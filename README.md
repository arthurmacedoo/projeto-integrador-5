# 📱 FinEdu — Educação Financeira Gamificada

> **Projeto Integrador 5 (PEI 5)**  
> Aplicativo de microlearning interativo focado na tomada de decisões financeiras seguras e proteção contra fraudes digitais (Pix e WhatsApp) para jovens e microempreendedores da Baixada Cuiabana.

## ✨ Destaques do Projeto

- **Roleplay Educativo:** Cenários reais do cotidiano onde cada escolha gera consequências imediatas e orientações práticas (*Dica do Guardião*).
- **Gamificação Humanizada:** Sistema de XP com 5 níveis de evolução que transformam visualmente o avatar do usuário.
- **Abordagem Não Punitiva:** Erros são tratados como oportunidade de aprendizado (recompensa parcial de XP e incentivo para continuar).
- **Suporte Offline:** Persistência automática em cache local para continuar aprendendo mesmo com conexão instável.
- **Interface Responsiva:** Design system inspirado na identidade visual acolhedora da Baixada Cuiabana, adaptado para web e dispositivos móveis.

| :--- | :--- |

| **Roteamento** | Expo Router (File-based) |
| **Estilização** | NativeWind v4 (Tailwind CSS) |
| **Gerenciamento de Estado** | Zustand |
| **Back-end & Nuvem** | Firebase (Authentication, Cloud Firestore e Hosting) |
